# Superpowers design archive

One-shot specs and implementation plans produced during agent-assisted design
sessions. **Horizons and checkboxes in `docs/living-specs/` are authoritative**
for what is shipped and what is next; mirror progress there when work lands.

## Reading older plans

Plans written before **2026-08-21** may reference Java packages as
`net.aincraft.*`. Runtime code now lives under **`dev.mintychochip.*`**
(`api`, `common`, `paper`). Treat package names in historical docs as
aliases unless a plan was refreshed after the migration.
