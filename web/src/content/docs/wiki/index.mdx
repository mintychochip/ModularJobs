## Overview

ModularJobs is a Paper plugin for configurable jobs and progression. Operators
define task actions, experience curves, optional economy payables, boosts, and
upgrade trees in the plugin data directory.

The bundled YAML, JSON, and CSV files are generic starter content. Replace or
extend them rather than treating the shipped amounts as a universal economy or
progression balance.

## Operator path

1. Apply the PostgreSQL schema out of band.
2. Configure the `database.yml` connection sections.
3. Review `config.yml`, especially the optional economy and editor settings.
4. Install only the optional integrations the server uses.
5. Restart after configuration changes.

See the [configuration reference](./reference/configuration/) for the active
keys and the [operations guide](./guides/operations/) for release and session
workflow notes.

## Distribution boundary

The Paper target is general-purpose, but the current UI is backed by Craftux,
which remains an explicitly deferred dependency-removal task. Mint and the
external Preferences plugin are not required to compile or start the base
plugin. The editor is disabled until an operator supplies an external REST API
and web URL.
